# desdj-echo-chamber

Invisible systems game for the DESDJ course (ISEP). You are the algorithm of a neighbourhood social network: amplify or hide posts from a basement control room and watch what it does to 14 neighbours, whose beliefs and fears you never see directly.

- Unity 6000.6.1f1, URP, Input System. Open the project and play `Assets/_Project/Scenes/Main.unity`.
