# Créditos

Assets 3D usados no protótipo, todos de licença livre. Confirmar a licença exata de cada pack no site de origem antes da entrega final.

- Kenney (kenney.nl): edifícios, estrada, veículos, personagens, relva e árvores.
- KayKit (Kay Lousberg), Furniture Bits: mobília e objetos da sala (ficheiros com prefixo `kk-`).
- pmndrs market (poimandres): alguns modelos soltos (por exemplo plantas e objetos pequenos).

O código do protótipo usa three.js (MIT).

Unity port: all sound effects and ambience are synthesised in code (`ProceduralAudio`). Procedural textures are generated by `TextureGen`. Packages: Cinemachine, glTFast, Unity AI Navigation, Input System, Newtonsoft Json (Unity registry).
